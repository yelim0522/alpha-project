# 예산 계획 및 2주차 계획

> 제출용. 승인 한도는 600,000원이지만 이번 주 계획은 **약 6만원(최소안)** 으로 충분하며, 나머지는 사용하지 않고 남긴다.
> 클라우드 GPU 시세는 2026-09 기준 추정치(환율 1 USD ≈ 1,380원 가정), 실제 결제 시 ±20% 변동 가능.

---

## 1. 돈을 어디에 써야 하는가 — 근거

1주차 초안의 한계(§6) 세 가지 중 **돈으로 해결되는 것**은 하나다:

| 한계 | 해결 수단 | 비용 발생? |
|---|---|---|
| 예측기 과대 정확 (prep% 100%) | 공개 궤적 데이터셋 재생 | **무료** (nuScenes, T-Drive, Porto Taxi 모두 무료 공개) |
| P=4·활성화 직렬화 가정에 측정 근거 없음 | vLLM 마이크로벤치 실측 | **GPU 시간 필요** (구매 아님, 시간 단위 임대) |
| 시뮬레이션 전용 | 위 실측으로 핵심 상수 대체 | 위와 동일 |

GPU는 **빠를 필요가 없고 모델이 메모리에 들어가기만 하면** 되므로, 고가 카드(A100/H100)는 불필요하다. 측정 목적은 전체 프로토타입이 아니라 **시뮬레이터 상수 두 개(배칭 병렬도 P, 활성화 직렬화 δ)의 실측 근거 확보**로 한정한다.

또한 시뮬레이터 상수는 이미 Pallas 논문의 실측값으로 K=1–4 구간을 ±10% 이내로 맞춘 상태이므로, 실측은 "근거 없는 가정을 채우는 것"이 아니라 "간접 보정을 직접 측정으로 확인하는 것"이다. 따라서 P∈{2,4,8} 민감도(시뮬레이션, 비용 0)를 먼저 수행하고, GPU 측정은 그 뒤에 소규모로 한다.

## 2. 예산 내역 (최소안)

| # | 항목 | 규격 | 수량 | 단가(추정) | 금액 |
|---|---|---|---|---|---|
| 1 | AI 코딩 도구 구독 | Claude Pro (시뮬레이터 개발·논문 작성 보조) | 1개월 | 약 $20 | **약 28,000원** |
| 2 | 클라우드 GPU 임대 (vLLM 마이크로벤치) | RTX A6000 48GB 또는 L40 48GB (Vast.ai / RunPod) | 20–25 시간 | 약 800–1,100원/h | **약 20,000–28,000원** |
| 3 | 클라우드 스토리지 (모델 가중치 캐시) | 100 GB × 1주 | 1 | 약 $0.10/GB/월 | **약 3,000원** |
| | **합계** | | | | **약 51,000–59,000원** |

예비비는 별도로 잡지 않고, 32B 모델 측정이 추가로 필요해질 경우에만 A100 80GB 20시간(약 4–5만원)을 추가 신청한다.

### 항목별 목적

- **#1 Claude Pro**: 시뮬레이터 코드 수정(궤적 재생 모듈, 민감도 스윕), 측정 스크립트 작성, 초안 v0.5 문장 정리에 사용.
- **#2 GPU 20–25시간 (A6000 48GB, Qwen3-14B)**:
  - Qwen3-14B(BF16 약 28 GB)는 24 GB 카드에 들어가지 않고, 양자화하면 prefill 속도가 바뀌어 측정 목적에 맞지 않음 → 48 GB 카드 선택
  - 동시 prefill 요청 수 n ∈ {1,2,4,8,16}에 대한 처리량 곡선 → **배칭 병렬도 P** (선형 구간의 끝)
  - 문맥 길이 {2k, 4k, 8k, 16k}별 prefill 시간 → 시뮬레이터 `prefill_rate`(14B: 4,700 tok/s) 검증
  - 프리픽스 캐시 활성화 시 첫 토큰 지연, 동시 활성화 k ∈ {1,2,4}에서의 증가 → **활성화 지연·직렬화 δ**
  - 시간 배분: 환경 세팅·모델 다운로드 3–4h, 측정 6–8h, 재실행 여유 8–10h
  - 14B는 논문 메인 모델(Qwen3-32B)과 같은 계열이므로 "같은 아키텍처에서 P가 얼마인가"를 보이기에 충분
- **#3 스토리지**: 인스턴스를 껐다 켤 때 28 GB 가중치를 다시 받지 않도록 볼륨 유지. 측정 완료 후 삭제.

### 왜 서버 간 KV 전송(2-GPU) 측정은 뺐나
- 2-GPU 노드는 시간당 3–5천원으로 비싸고 vLLM KV connector 설정에 시간이 많이 든다.
- 백홀 전송 시간은 KV 크기(토큰 × 256 KiB) ÷ 링크 대역폭으로 결정론적이며, Pallas Table 1의 Full-Copy 수치로 이미 −6~−8% 이내로 검증되어 있다.
- 필요하면 단일 GPU 안에서 GPU→CPU→GPU 복사로 활성화 비용을 근사한다.

# alpha-project

MEC(멀티액세스 엣지 컴퓨팅)를 메인 주제로 하는 논문 작업 저장소.

## 서브주제: 이동성 환경 엣지 LLM 서빙의 선제적 백홀 혼잡 평탄화 KV 마이그레이션

사용자가 이동해 서빙 엣지 서버가 바뀔 때, 진행 중인 LLM 세션의 KV 캐시(대화 상태)를
전송(transfer)할지 재계산(prefill)할지 결정하는 문제를 다룹니다. 타겟 논문(다중 사용자
반응형 스케줄러) 1편을 개선하되, novelty의 핵심은 "예측/프리페치"라는 기법이 아니라
반응형 스케줄러가 원리적으로 할 수 없는 "시간축 백홀 혼잡의 선제적 평탄화"라는 결정에
둡니다. 예측·우선순위 기반 선제 전송·적응적 재계산은 이를 구현하는 경량 수단입니다.

- `paper/draft.md` — 논문 초안(서론·문제제기·시스템 모델·제안 방법·실험 설계)
- `paper/semester-plan-2026-2.md` — 2026-2학기(약 3.5개월) 연구 계획. **여기서 시작**
- `paper/related-work-map.md` — ctHO / ImpactHO / Pallas / 초안 비교
- `paper/novelty-memo.md` — 2주차 기여 게이트 템플릿
- `paper/references.md` — 24~26년 중심 참고문헌
- `sim/` — 표준 라이브러리 기반 이산시간 시뮬레이터(정책 비교)

### 빠른 실행

```bash
cd sim && python3 run.py
```

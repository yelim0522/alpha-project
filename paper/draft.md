# 이동성 환경의 엣지 LLM 서빙에서 KV 캐시 상태 이전 문제의 예측 기반 선제 프리페치 기법

> 작업 중 초안 (v0.1) — 팀 공통 주제 **MEC** 하위, 서브주제 "이동성 기반 서비스 마이그레이션 × LLM".
> 방식: 타겟 논문 1편 지정 후 알고리즘/아이디어 개선(방식 B).

---

## 1. 서론

### 1-1. 연구 배경

멀티액세스 엣지 컴퓨팅(Multi-access Edge Computing, MEC)은 지연에 민감하고 연산량이 큰 애플리케이션을 사용자 인접 서버로 이전함으로써 단말의 처리 한계를 보완하는 패러다임이며, 5G의 보급과 6G의 등장에 따라 그 중요성이 지속적으로 확대되어 왔다. 최근에는 대규모 언어 모델(Large Language Model, LLM) 기반 대화·에이전트 서비스를 엣지 서버에서 직접 서빙하려는 시도가 활발하다. 클라우드 대비 저지연·프라이버시 보존이라는 MEC 본연의 이점을 LLM 서빙에 결합할 수 있기 때문이다 [target, survey1, survey2].

그러나 LLM 서빙은 기존 MEC의 상태 없는(stateless) 태스크 오프로딩과 근본적으로 다르다. LLM은 자기회귀적으로 토큰을 생성하며, 지금까지의 대화 문맥을 **키-값 캐시(Key-Value cache, 이하 KV 캐시)**라는 상태로 유지한다. 즉 사용자의 LLM 세션은 서버에 상태가 귀속된 **상태 유지(stateful) 서비스**이다. 이 특성은 사용자가 이동할 때 문제를 일으킨다. 사용자가 셀 경계를 넘어 서빙 엣지 서버가 바뀌면(핸드오버), 새 서버는 대화 문맥을 갖고 있지 않으므로 서비스가 끊긴다.

### 1-2. 문제 제기

핸드오버 시 대상 서버에서 세션을 재개하려면 KV 캐시를 복원해야 하며, 방법은 크게 두 가지다. 첫째는 원 서버의 KV 캐시를 **백홀 네트워크로 전송**하는 것이고, 둘째는 원본 대화 텍스트만 넘겨 대상 서버가 **prefill 연산으로 KV 캐시를 재계산**하는 것이다. 전자는 대화가 길수록 KV 캐시가 커져 전송이 비싸지고, 후자는 재계산에 GPU 시간이 든다. 본 연구가 개선 대상으로 삼는 타겟 논문 [target]은 이 두 방법을 결합하여, prefill 길이와 백홀 KV 전송 스케줄을 함께 결정함으로써 다중 사용자 핸드오버의 최악 사용자 지연을 최소화하는 해법을 제시한다.

타겟 논문의 결정 구조를 분석하는 과정에서, 해당 프레임워크가 **핸드오버가 이미 발생한 시점에 반응적으로(reactive)** 전송/재계산을 결정하도록 구성되어 있음을 확인하였다. 이는 실용적 설계이나 두 가지 정보 공백을 낳는다.

첫째, **미래 이동 정보의 부재**이다. 사용자가 곧 어느 서버로 이동할지에 대한 예측이 결정에 반영되지 않으므로, 핸드오버 이전에 KV 캐시를 미리 전송(prefetch)해 둘 기회를 활용하지 못한다. 그 결과 상태 이전 비용 전체가 핸드오버 순간에 집중되어 서비스 중단이 길어진다.

둘째, **다중 사용자 백홀 경합의 비가시성**이다. 여러 사용자가 근접한 시점에 같은 방향으로 이동하면, 이들은 서로의 결정을 알지 못한 채 각자 독립적으로 동일 백홀 링크를 통해 KV 캐시를 전송한다. 이때 백홀 대역폭이 순간적으로 공유·고갈되어 전송 지연이 급증하는 **핸드오버 herding**이 발생한다. 저이동성 구간에서는 두드러지지 않으나, 고이동성·고밀도 구간에서 반복적으로 재현된다.

주목할 점은, 이 문제가 단순한 정책 학습 부족이 아니라 **결정 시점과 상태 관측 범위의 구조적 한계**에서 기인한다는 것이다. 반응형 정책은 아무리 잘 조정되어도, 관측 시점에 존재하지 않는 미래 이동 정보와 타 사용자의 동시 전송 부하를 근거로 결정을 내릴 수 없다.

### 1-3. 연구 공헌

본 논문의 공헌은 다음 네 가지이다.

- **첫째**, 대표적 엣지 LLM 핸드오버 프레임워크 [target]의 결정 구조를 분석하여, 미래 이동 정보와 다중 사용자 백홀 경합이 상태 이전 결정에 구조적으로 누락되는 정보 공백을 규명하고, 이것이 정책 재조정만으로는 해소되지 않는 한계임을 통제실험으로 뒷받침한다.
- **둘째**, 사전 정의된 상태 이전 정책의 파라미터를 변경하지 않는 **재학습 불필요(zero-retraining) 추론 시점 보정 모듈**을 제안한다. 본 모듈은 이동 예측 기반 **선제적 KV 프리페치**와 백홀 경합에 연동한 **적응적 부분 재계산 비율 조정**, 그리고 저이동성 구간에서의 불필요한 개입을 막는 **안전 게이팅**으로 구성된다.
- **셋째**, 전량 전송·전량 재계산·반응형 하이브리드라는 대안적 접근과의 비교를 통해, 동일 정보라도 **예측 기반 선제 이전**이 반응형 결정보다 구조적 결함 해소에 더 효과적임을 실증한다.
- **넷째**, 평균 지연이라는 단일 집계 지표의 취약성을 고려하여, 구조적 원인을 직접 포착하는 지표(**핑퐁 핸드오버 횟수**, **백홀 경합도**)와 개입의 인과성을 뒷받침하는 지표(**프리페치 발동률**)를 분리한 다층 검증 설계를 제시한다.

## 2. 관련 연구

### 2-1. 엣지 LLM 서빙과 KV 캐시 관리
연속 배칭, KV 캐시 계층화·압축·재사용 등 LLM 서빙 최적화가 활발히 연구되어 왔다 [kvsurvey, kvsched, mtds]. 그러나 이들 대부분은 **단일 데이터센터/서버 내부**의 처리량·메모리 최적화에 초점을 두며, 사용자 이동으로 인한 서버 간 세션 연속성 문제는 별도로 다루지 않는다.

### 2-2. 서비스 마이그레이션·핸드오버
이동성 기반 서비스 마이그레이션은 MEC의 핵심 문제로, 궤적 예측과 심층강화학습을 결합한 접근이 제안되어 왔다 [srcl, magrl]. 그러나 이들은 상태를 **전송해야만 하는 고정 크기 객체**로 가정하며, LLM 세션 특유의 (i) 토큰 수에 비례하는 동적 상태 크기, (ii) 전송의 대안인 재계산(prefill)이라는 선택지를 고려하지 않는다.

### 2-3. 엣지 LLM 핸드오버(직접 관련)
최근에서야 KV 캐시 상태 이전을 명시적으로 다루는 연구가 등장하였다. [target]은 전송과 prefill 재계산을 함께 스케줄링하여 핸드오버 지연을 최소화하고, [ilcp]는 순환 상태를 압축하여 소형 메시지로 전송함으로써 핸드오버 후 콜드 스타트를 완화한다. 다만 두 접근 모두 반응형이며, 다중 사용자 예측·경합을 결정에 통합하지는 않는다. 한편 [dapo]는 이동성을 고려하나 모델 분할(partitioning)에 초점을 두어 본 연구와 문제 축이 다르다. 본 연구는 [target]을 직접 개선 대상으로 삼되, 학습 구성의 변경이 아니라 **추론 시점의 예측 기반 선제 보정**으로 접근한다는 점에서 위 연구들과 구별된다.

## 3. 시스템 모델 및 문제 진단

### 3-1. 타겟 시스템 모델
2차원 평면에 배치된 엣지 서버 집합 $\mathcal{M}=\{1,\dots,M\}$과 이동하는 사용자 집합 $\mathcal{K}=\{1,\dots,K\}$를 고려한다. 각 사용자 $k$는 시점 $t$에 진행 중인 LLM 대화를 가지며, 누적 토큰 수 $L_k(t)$는 디코딩 진행에 따라 시간에 대해 증가한다. 사용자 $k$는 매 시점 커버리지 내 최근접 서버 $s_k(t)$로부터 서빙받으며, $s_k(t)\neq s_k(t-1)$이면 핸드오버가 발생한다.

### 3-2. KV 캐시 상태 이전 비용 모델
사용자 $k$의 KV 캐시 크기는 토큰 수에 비례한다:
$$
\text{KVsize}_k(t) = c \cdot L_k(t),
$$
여기서 $c$는 토큰당 KV 바이트 수(레이어·헤드 차원에 의존하는 상수)이다. 핸드오버 시 대상 서버 $m$에서 세션을 재개하려면 $L_k$개 토큰 분량의 KV가 필요하며, 이 중 앞쪽 $p$개 토큰은 대상 서버에서 prefill로 재계산하고 나머지 $L_k-p$개 토큰의 KV는 백홀로 전송한다고 하자. 재계산과 전송은 병렬로 수행되므로, 핸드오버 지연은
$$
D_k(p) = \max\!\Big( \underbrace{\tfrac{p}{v_m}}_{\text{재계산}},\ \underbrace{\tfrac{c\,(L_k-p)}{B}}_{\text{전송}} \Big),
$$
로 근사된다. $v_m$은 서버 $m$의 prefill 속도(토큰/초), $B$는 유효 백홀 대역폭(바이트/초)이다. $D_k(p)$를 최소화하는 최적 prefill 길이는 두 항이 같아지는 지점에서 얻어진다:
$$
p^\star = \frac{c\,v_m\,L_k}{B + c\,v_m},\qquad
D_k^\star = \frac{c\,L_k}{B + c\,v_m}.
$$
$p=0$(전량 전송)과 $p=L_k$(전량 재계산)은 이 하이브리드 최적의 특수 경우이며, $D_k^\star$는 두 극단보다 항상 작거나 같다. **이 재계산-전송 트레이드오프는 상태를 전송할 수밖에 없는 일반 서비스 마이그레이션에는 존재하지 않는, LLM 자기회귀 구조 고유의 결정 축이다.**

### 3-3. Herding 메커니즘과 통제실험
문제는 $B$가 상수가 아니라는 데 있다. 동일 백홀 링크를 통해 동시에 상태를 이전하는 사용자 수 $n(t)$가 늘면 유효 대역폭은 $B_{\text{eff}} \approx B/(1+\alpha\, n(t))$로 감소한다. 고이동성·고밀도 구간에서 다수 사용자가 근접 시점에 같은 방향으로 이동하면 $n(t)$가 급증하여 전송 지연이 폭증한다. 반응형 정책은 이 동시 부하를 결정 시점에 관측하지 못하므로, 이미 경합이 발생한 뒤에야 병목을 겪는다.

이 현상이 정책 조정 부족이 아니라 구조적 한계임을 확인하기 위해, 고이동성 조건에 특화하여 반응형 하이브리드의 파라미터를 재탐색하는 통제실험을 수행한다. 특화 조정 이후에도 핸드오버 herding과 지연 열화가 재현된다면, 이는 관측되지 않는 미래 이동·경합 정보를 근거로는 결정을 개선할 수 없다는 원리적 한계를 뒷받침한다.

## 4. 제안 방법

### 4-1. 설계 원칙
(i) **재학습 불필요성**: 기존 상태 이전 정책의 파라미터를 갱신하지 않고 추론 시점에만 개입한다. (ii) **예측 기반 선제성**: 핸드오버 이전에 이동을 예측하여 KV를 점진 전송한다. (iii) **부하 비례 개입**: 저이동성·저경합 구간에서는 개입을 억제하여 불필요한 백홀 낭비를 막는다.

### 4-2. 구성 요소
- **이동 예측기**: 최근 위치·속도로 사용자 $k$의 다음 서빙 서버 후보 $\hat{m}_k$와 핸드오버 예상 시점을 추정한다(선형 외삽 또는 경량 시퀀스 모델).
- **선제 프리페치기**: $\hat{m}_k$로 향할 확률이 높고 경합이 낮은 구간에서 KV 캐시를 미리 점진 전송한다. 이미 전송된 토큰 수 $\pi_k$만큼 핸드오버 시 잔여 전송량이 줄어든다.
- **적응적 재계산 비율기**: 핸드오버 시점의 백홀 경합도에 따라 $p$를 $p^\star$ 주변에서 조정한다(경합↑ → 재계산 비중↑).
- **핑퐁 게이트**: 사용자가 곧 원 서버로 복귀할 것으로 예측되면 상태 이전을 보류·축소한다.

### 4-3. 핸드오버 지연(제안)
프리페치를 반영하면 잔여 토큰은 $L_k-\pi_k$이며, 핸드오버 지연은
$$
D_k^{\text{prop}} = \max\!\Big( \tfrac{p}{v_m},\ \tfrac{c\,(L_k-\pi_k-p)}{B_{\text{eff}}} \Big),
$$
로, 프리페치가 성공한 만큼 전송 항이 감소한다. 프리페치 강도는 안전 게이트 $\eta(u)=\eta_{\max}\cdot\sigma(\gamma(u-\theta))$로 조절하며, $u$는 최근 시간창의 이동/경합 수준이다.

### 4-4. 알고리즘 개요
1. 매 시점: 이동 예측 → 게이트 통과 시 후보 서버로 KV 점진 프리페치.
2. 핸드오버 발생 시: 프리페치 잔량과 현재 경합으로 $p$ 결정 → $D_k^{\text{prop}}$로 세션 재개.
3. 핑퐁 예측 시: 이전 보류.
> 기존 정책 $\pi$는 그대로 두고 입력(잔여 상태·경합 추정)만 보정되므로, 재학습 없이 결정 결과만 교정된다.

## 5. 실험 설계(예정)

### 5-1. 지표 계층화
- **주 지표**: 핸드오버 지연(평균/p99), **핑퐁 핸드오버 횟수**(herding 직접 포착, 사후 보정으로는 개선되지 않음).
- **보조 지표**: **프리페치 발동률**(개입-개선 인과 확인), 백홀 경합도.
- **부가 지표**: 서비스 중단 시간, 총 백홀 사용량, 로컬 재계산 비율.

### 5-2. 베이스라인
전량 전송 / 전량 재계산 / 반응형 하이브리드([target] 근사) / **제안(예측 선제 프리페치)**.

### 5-3. 환경
실제 이동 궤적(T-Drive, Rome/Porto taxi 등) 또는 랜덤 웨이포인트, 대화 길이 분포(LMSYS-Chat-1M 등에서 표집). 서버 5~10, 사용자 수십~수백, 다수 seed. 상세는 `sim/` 시뮬레이터 참조.

---

## 6. 결론(예정)
사용자 이동으로 서빙 엣지 서버가 바뀔 때 LLM 세션의 KV 캐시를 잇는 문제에서, 반응형 상태 이전이 미래 이동과 다중 사용자 백홀 경합을 구조적으로 누락함을 규명하고, 재학습 없는 예측 기반 선제 프리페치·적응적 재계산 보정 모듈을 제안한다. 향후 원 논문 규모로 확장한 본실험으로 재현성과 통계적 신뢰도를 확보한다.
